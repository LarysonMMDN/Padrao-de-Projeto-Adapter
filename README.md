# Calculadora JavaFX

Projeto desenvolvido em Java com JavaFX para apresentação acadêmica na Faculdade FATESG.

O principal objetivo foi aplicar na prática o padrão de projeto **Adapter**, demonstrando como adaptar interfaces e integrar funcionalidades.

A calculadora realiza duas operações matemáticas:

- **Potência:** cálculo utilizando base e expoente.
- **Raiz quadrada:** cálculo da raiz de um número.

### Tecnologias utilizadas
- Java
- JavaFX
- FXML
- Design Pattern Adapter

**Finalidade:** atividade acadêmica com foco na aplicação prática do padrão Adapter e no desenvolvimento em Java.
